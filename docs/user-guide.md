# 使用指南

见微适合围绕一个具体问题整理判断，例如「我们是否应换用某个软件？」。先写一个可以被资料挑战的假设，再分别收集支持和反对它的证据。

## 从案例到自己的项目

首次打开显示 AI 泡沫案例。点击「加载 AI 泡沫示例」可以恢复案例；点击「编辑项目」能直接改写现有题目，原有材料会保留。要完全从头开始，点击「新建自己的项目」。切换会替换当前工作区，先「下载项目文件」就能留住旧项目。

## 资料、观点和证据怎么区分

资料是原始依据：一篇文章、一份访谈、一个财报或个人笔记。观点是你基于资料作出的判断。一条观点可以关联多份资料；添加观点时勾选相应资料即可。证据线索说明某份资料为什么支持或挑战项目的当前假设，不能只因为引用了资料就把推断当成事实。

添加资料时，把作者、日期或背景放进「资料背景」，把自己的整理放进「摘要或笔记」。在「证据边界」写明材料不能证明什么。工具不会自动抓取链接内容，也不会替你核实原文。

## 修改与删除

每份资料、观点、证据和判断记录都有编辑入口。编辑窗口中可以保存或删除；删除资料会自动移除各记录对它的关联。删除操作没有撤销按钮，重要内容先下载项目文件备份。

## 记录变化

判断记录按添加顺序展示，日期由你填写，不自动按日期排序。写清楚当时的判断与变化原因，关联触发修订的资料。底部结论用于保存当前立场与下一步，它与历史判断记录独立，不会自动生成新记录。

## 保存与分享

表单提交后自动保存；底部结论随编辑自动保存。localStorage 只属于当前浏览器和网站地址，换浏览器或清除网站数据无法恢复。点击「下载项目文件」保存 JSON；在另一台设备打开网站并导入该文件，可以继续编辑。

发给别人的 JSON 包含项目中的全部文字及资料链接，请检查是否有私人内容。接收者导入后得到自己的副本，不会改变你的记录。Markdown 报告适合阅读或汇报；JSON 才是可以再次导入的项目文件。

## AI 案例补充

AI 泡沫案例展示了一次完整研究如何组织。案例中的判断记录是预先整理的示例，并非你的个人研究历史。「示例 · CapEx」是案例原有的固定数据表，不是通用编辑器；修改项目资料不会修改该表。新建空白项目时该页不出现。
